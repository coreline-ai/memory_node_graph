최근 업데이트: `2026-08-07 KST` — GitHub 스타일 README, Shields 배지, 현재 앱 그래프 6종·대시보드 5구역 스크린샷과 카탈로그를 추가했다. 이 업데이트는 문서·시각 기준선만 확정했으며 Phase 1 통합 런타임 코드는 아직 시작하지 않았다.

이 문서는 분리형 로컬 Connector를 API Key 없는 통합 Codex OAuth 런타임으로 전환하는 개발 범위를 고정하고, 구현이 목적 밖으로 확장되지 않도록 하기 위한 작업 문서다.

## 개발 목적

- 현재 규칙 기반 Markdown 파서·D1·발광형 그래프 GUI를 그대로 유지한다.
- OpenAI API와 API Key 없이 `@openai/codex-sdk`가 Codex/ChatGPT OAuth 세션을 사용하게 한다.
- 사용자가 `npm run connector:start`를 별도로 실행하지 않는 배포 구조로 전환한다.
- Connector heartbeat와 `NO SIGNAL` UI를 OAuth 세션·작업 상태로 교체한다.
- Markdown 추가 후 규칙 그래프 저장, 선택적 OAuth 보강, 화면 snapshot 갱신까지 자동 연결한다.

## 개발 범위

- 현재 Connector의 Codex 실행·작업 처리 책임을 통합 서버 런타임으로 이동
- 서버 전용 OAuth 세션 저장·만료·재로그인 상태 계약
- GitHub `gh auth` 의존을 서버 측 GitHub OAuth 경계로 교체
- heartbeat·Connector token·NO SIGNAL UI와 복구 문구 제거
- 기존 D1 queue·Lease·결과 검증의 내부 재사용 여부 정리
- Markdown 처리 완료 후 corpus cache 무효화와 클라이언트 자동 재조회
- 공유 웹의 공개 읽기·인증된 쓰기·비공개 저장소 메타데이터 보호
- 로컬·운영 배포 및 회귀 테스트 문서화

## 제외 범위
