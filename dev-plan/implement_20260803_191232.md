> **문서 상태:** 그래프 연출 이력은 유효하다. 인증·Codex 실행에 관한 현재 정본은 [현재 OAuth 런타임 방향](../docs/current-oauth-runtime.md), 최신 계획은 [implement_20260807_203534.md](./implement_20260807_203534.md)다.

이 문서는 AI Systems Atlas의 발광 프리셋 의미를 명확히 하고, 선택·라벨·궤도·하단 메뉴의 시각 가독성을 보강하며, 실제 지식 데이터와 분리된 최대 밀도 시각 데모를 실행할 수 있도록 하는 후속 개발 범위를 고정한다.

## 개발 목적

- `초신성`을 선택하면 데스크톱과 작은 화면 모두에서 전체 발광 강도가 명확한 최댓값으로 보이게 한다.
- `전체 우주`는 단순 필터 해제가 아니라 모든 노드와 관계가 충분히 밝게 보이는 전체 탐색 상태로 정의한다.
- 에이전트·지능의 기억 등 특정 렌즈를 선택했을 때의 집중 강조와 전체 발광 강도를 서로 독립적으로 조절한다.
- 기존 `기본`, `브라이트`, `초신성` 프리셋을 유지하면서 별도의 `발광 조절` 메뉴에서 세부 값을 조정할 수 있게 한다.
- 선택 노드와 1·2단계 관계가 그래프 내부에서도 즉시 구분되도록 선택 비콘과 단계별 발광 위계를 제공한다.
- 화면 배율과 선택 상태에 따른 라벨 LOD를 적용해 문장형 라벨 충돌을 줄인다.
- 궤도 보기의 링이 관계 깊이를 뜻한다는 사실을 최소한의 단계 표기로 전달한다.
- 기능 증가로 과밀해질 하단 도구 모음을 `보기`, `데이터`, `연출` 책임으로 재구성한다.
- 실제 저장 데이터에 영향을 주지 않는 `최대 밀도 쇼케이스`를 제공해 500개 노드와 2,000개 관계의 시각적 인상을 즉시 확인할 수 있게 한다.

## 개발 범위

- 하단 `기본 | 브라이트 | 초신성` 선택기를 유지한다.
- 선택기 옆에 현재 디자인 언어를 따르는 `발광 조절` 팝오버 버튼을 추가한다.
- 발광 조절 메뉴에 `전체 밝기`, `관계선`, `후광`, `배경 입자`, `선택 대비` 제어를 제공한다.
- 프리셋과 세부 설정을 하나의 순수 설정 계약으로 관리한다.
- 슬라이더를 변경하면 화면 상태를 `커스텀`으로 표시하고, `초기화`로 마지막 선택 프리셋 값으로 돌아간다.
- `전체 우주 + 초신성`은 모든 노드·관계의 최고 전체 발광 상태가 되게 한다.
- `렌즈 선택 + 초신성`은 선택 영역을 최고 밝기로 유지하고 비선택 영역은 선택 대비 설정에 따라 낮춘다.
- 작은 화면에서도 초신성 밝기를 브라이트로 강제 하향하지 않는다.
- 모바일·저성능 환경에서는 밝기 대신 픽셀 비율, 입자 수, 광자 수, 관계선 갱신 빈도를 낮춘다.
- 별자리·성운·궤도 세 보기에서 동일한 발광 설정 계약을 사용한다.
- 선택 노드에 코어·외곽 후광 비콘을 적용하고 직접 관계와 확장 관계를 서로 다른 밝기로 표시한다.
- 선택 관계에만 짧은 광자 흐름을 적용하며 모든 관계선의 상시 애니메이션은 사용하지 않는다.
- 라벨은 화면 배율·선택 거리·노드 중요도를 기준으로 표시하며 충돌 시 낮은 우선순위 라벨부터 숨긴다.
- 궤도 링에는 `CORE`, `DEPTH 01`, `DEPTH 02` 의미 표기를 낮은 대비로 제공한다.
- 하단 컨트롤을 `보기`, `데이터`, `연출` 세 그룹으로 재배치하고 활성 상태를 그룹 요약 문구로 표시한다.
- 하단 보기 선택 영역에 `쇼케이스` 메뉴를 추가하고 `현재 지식 데이터`와 `최대 밀도 데모`를 전환한다.
- 최대 밀도 데모는 기존 500 노드·2,000 관계 성능 fixture를 재사용하며 별도의 백엔드 데이터나 저장소를 만들지 않는다.
- 최대 밀도 데모 진입 시 별자리 보기, 전체 우주, 초신성, 라벨 끄기, 자동 회전, 화면 맞춤을 권장 데모 상태로 적용한다.
- 데모 중에는 `DEMO · 500 NODES / 2,000 EDGES`와 `저장되지 않는 시각 샘플`임을 화면에 명확히 표시한다.
- 데모 종료 시 실제 그래프를 다시 불러오고 진입 전 보기·렌즈·발광·라벨·자동 회전 상태를 복원한다.
- 공유 가능한 사용자용 URL과 읽기 요청은 `showcase=max` 계약을 사용하고 내부 개발·성능 파라미터 `fixture=500x2000`은 UI에서 노출하지 않는다.

## 공통 진행 규칙

- 이 계획은 발광 UX 후속 작업이며 사용자의 구현 승인 전에는 Phase 1을 시작하지 않는다.
- 각 Phase는 앞선 Phase의 자체 테스트 완료 후에만 시작한다.
- 구현 중 발생한 이슈는 해당 Phase에서 수정하고 기록한다.
- 체크박스 상태를 실제 진행 상태와 맞게 업데이트한다.
- 문서에 없는 범위 확장은 하지 않는다.
- 요구사항이 불명확하면 가능한 케이스를 나누고 확인 후 진행한다.
- 렌더링 설정 계산은 가능한 한 순수 함수로 분리하고 Three.js 객체 갱신은 렌더러 경계 안에 둔다.
- 새 의존성을 추가하지 않고 현재 React·Three.js·CSS 구조를 사용한다.
- 밝기, 포커스 강조, 렌더링 품질을 서로 다른 책임으로 유지한다.
- `prefers-reduced-motion`은 움직임을 줄이되 사용자가 선택한 정적 밝기까지 임의로 낮추지 않는다.
- 구현 완료 후에도 사용자 승인 없이 배포하지 않는다.

## 핵심 동작 계약

### 프리셋

| 프리셋 | 전체 밝기 | 관계선 | 후광 | 배경 입자 | 의미 |
|---|---:|---:|---:|---:|---|
| 기본 | 75% | 35% | 45% | 35% | 장시간 탐색과 높은 가독성 |
| 브라이트 | 100% | 55% | 70% | 65% | 권장 기본 상태 |
| 초신성 | 150% | 100% | 100% | 100% | 전체 발광 최댓값 |

- 위 수치는 UI 표시 기준이며 Shader·Bloom의 실제 안전 범위로 정규화한다.
- 초신성은 `light`, Bloom, 관계선 가시성의 최고 프리셋이어야 한다.
- 초신성이라도 최종 색상과 alpha는 하얗게 포화되지 않도록 렌더러 안전 상한을 적용한다.

### 전체 우주와 선택 렌즈

- `전체 우주`에서 노드 기본 Boost를 현재 `1.0`보다 높은 전체 가시 수준으로 조정한다.
- 관계선 기본 밝기를 현재 약 `0.33`보다 높여 전체 연결 구조를 읽을 수 있게 한다.
- 선택 렌즈는 전체 밝기와 별개로 선택 노드를 강조하고 비선택 노드를 낮춘다.
- 최종 밝기는 `전역 발광 × 보기 보정 × 포커스 강조` 순서로 합성하고 마지막에 안전 상한을 적용한다.
- `전체 우주 + 초신성`과 `선택 렌즈 + 초신성`은 모두 강하게 빛나지만, 후자는 선택 영역의 대비가 추가되어야 한다.

### 발광 조절 메뉴

| 항목 | 범위 | 기본 역할 |
|---|---:|---|
| 전체 밝기 | 50~150% | 노드 코어·코로나의 전역 밝기 |
| 관계선 | 20~100% | 비선택 상태를 포함한 관계선 가시성 |
| 후광 | 0~100% | Bloom 강도와 코로나 확산 |
| 배경 입자 | 0~100% | 먼지·광자 opacity와 활성 수준 |
| 선택 대비 | 낮음·보통·강함 | 선택/비선택 노드의 상대 Boost |

- 프리셋 버튼을 누르면 다섯 설정을 해당 기준값으로 즉시 복원한다.
- 사용자가 한 항목이라도 변경하면 `커스텀` 상태를 표시한다.
- 팝오버는 키보드로 열고 닫을 수 있어야 하며 각 제어에는 현재 백분율 또는 단계 문구를 제공한다.

### 최대 밀도 쇼케이스

| 상태 | 데이터 | 기본 연출 | 저장 동작 |
|---|---|---|---|
| 현재 지식 데이터 | 현재 `/api/graph` 결과 | 사용자의 기존 보기·렌즈·발광 상태 | 기존 동작 유지 |
| 최대 밀도 데모 | 기존 `500x2000` fixture | 별자리·전체 우주·초신성·라벨 끄기·자동 회전·화면 맞춤 | 저장·수정 없음 |

- 하단 메뉴명은 `쇼케이스`, 활성 버튼 문구는 `최대 밀도 · 500 / 2K`로 표시한다.
- 데모는 성능 fixture를 시각 프레젠테이션용으로 감싸는 UI 모드이며 실제 지식 그래프처럼 오인되지 않게 한다.
- 사용자가 데모 상태에서 URL을 공유하면 같은 데모 화면을 열 수 있지만 서버 데이터는 생성하지 않는다.
- `/api/graph?showcase=max`는 환경과 무관하게 결정적 인메모리 샘플을 읽기 전용으로 반환하고, 기존 `fixture=500x2000`의 개발 환경 전용 계약은 유지한다.
- 작은 화면에서도 노드·관계 개수는 유지하고 픽셀 비율·입자 효과 등 렌더 품질만 자동 조정한다.
- 데모 진입 전 상태는 메모리에서만 보관하고, 데모 종료 시 가능한 항목을 원래 상태로 복원한다.

### 선택·라벨·궤도 시각 위계

| 요소 | 기본 상태 | 선택 상태 | 목적 |
|---|---|---|---|
| 선택 노드 | 기존 발광 | 밝은 코어·넓은 외곽 코로나·저속 호흡 링 | 화면에서 선택 지점을 즉시 식별 |
| 직접 관계 | 기본 관계선 | 노드·관계선 100% 강조 | 1단계 연결 추적 |
| 확장 관계 | 기본 관계선 | 직접 관계 대비 55~65% 강조 | 2단계 구조 인지 |
| 비관련 항목 | 전체 우주 밝기 | 15~25% 최소 가시성 유지 | 맥락을 잃지 않고 포커스 제공 |
| 관계 흐름 | 정적 관계선 | 선택 경로에만 짧은 광자 흐름 | 방향성과 연결 순서 전달 |

- 라벨 우선순위는 `선택 노드 > 직접 관계 > 확장 관계 > 중요 노드 > 일반 노드` 순서로 계산한다.
- 축소 상태에서는 선택·중요 노드, 보통 상태에서는 직접 관계, 확대 상태에서는 확장·일반 노드까지 단계적으로 표시한다.
- 충돌 라벨은 낮은 우선순위부터 숨기며 숨겨진 노드는 hover/focus 툴팁으로 이름을 확인할 수 있게 한다.
- 최대 밀도 쇼케이스는 라벨을 기본으로 끄고 hover/focus 툴팁만 제공한다.
- 궤도 표기는 `CORE · 선택 지식`, `DEPTH 01 · 직접 관계`, `DEPTH 02 · 확장 관계`를 사용한다.
- 궤도 단계 문구는 노드 선택 직후 잠시 밝아지고 이후 낮은 대비로 안정화한다.

### 하단 메뉴 정보 구조

| 그룹 | 포함 제어 | 활성 요약 예시 |
|---|---|---|
| 보기 | 별자리·성운·궤도 | `보기: 궤도` |
| 데이터 | 문서 관리·쇼케이스 | `데이터: 실제 지식` 또는 `데이터: 최대 밀도` |
| 연출 | 자동 회전·재정렬·라벨·발광 프리셋·발광 조절 | `연출: 초신성` |

- 기존 기능과 키보드 순서는 유지하되 시각적 구분선과 그룹 라벨로 책임을 명확히 한다.
- 데스크톱은 한 줄 그룹형 도구 모음을 사용하고 작은 화면은 그룹 단위 가로 스크롤 또는 압축 메뉴로 전환한다.
- 추가 제어가 들어와도 개별 버튼을 무한히 나열하지 않고 각 그룹 팝오버 안에 배치한다.
