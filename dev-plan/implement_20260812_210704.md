작성 일시: `2026-08-12 21:07:04 KST`

이 문서는 하단 그래프 제어 영역의 빈 공간을 실제 탐색 가치가 높은 옵션으로 보강하되, 기존 발광 GUI와 데이터 의미를 훼손하지 않도록 개발 범위를 고정하기 위한 작업 문서다.

## 개발 목적

- 선택한 지식의 관계 범위를 `전체·1단계·2단계`로 빠르게 좁혀 복잡한 그래프의 탐색성을 높인다.
- 저장된 근거 관계와 비저장 시각 연결을 하단 메뉴에서 즉시 구분한다.
- 현재 보이는 노드 집합을 그래프 viewport 안에 안정적으로 맞춘다.
- 노드 크기의 의미를 `유형·연결 수·균일` 중 선택할 수 있게 한다.
- 데스크톱의 비어 있는 하단 옵션 공간을 활용하되 작은 화면의 접근성과 기존 기능을 유지한다.

## UX·상태 계약

### 선택 범위

| 상태 | 노드 표시 | 관계 표시 | 선택 필요 | 기본값 |
|---|---|---|---|---|
| `전체` | 현재 투영의 모든 필터 통과 노드 | 모든 필터 통과 관계 | 불필요 | 선택이 없을 때 유일 상태 |
| `1단계` | 선택 노드 + 직접 이웃 | 선택 노드에 직접 연결된 관계 | 필요 | 아니오 |
| `2단계` | 선택 노드 + 직접 이웃 + 확장 이웃 | 직접 관계 + 2단계 확장 관계 | 필요 | 노드 선택 직후 기본값 |

- 노드 선택을 해제하면 범위는 `전체`로 복귀한다.
- `1단계·2단계`는 데이터 삭제나 재투영이 아니라 렌더 visibility mask로 동작한다.
- 선택 노드 상세 패널, 선택 비콘, 궤도 중심은 범위 변경 후에도 유지한다.
- 분야·유형·관계 필터와 교집합으로 적용한다.
- 범위 밖 노드는 점·라벨·관계선·raycast·키보드 포커스·화면 맞춤 대상에서 제외한다.
- URL의 기존 `node`는 유지하되 이번 범위에서는 선택 범위를 URL 파라미터로 추가하지 않는다.

### 관계 표시

| 상태 | 포함 계층 | 의미 |
|---|---|---|
| `전체` | structural + explicit + inferred + display | 현재 그래프 전체 표현 |
| `근거` | structural + explicit + inferred | 저장·검증 관계만 표시 |
| `시각` | display | 비저장 화면 연결만 검토 |
| `맞춤` | sidebar에서 선택한 임의 조합 | toolbar가 현재 사용자 조합을 표시 |

- `display`는 D1·분석·RAG에 포함되지 않는다는 기존 의미를 유지한다.
- toolbar 프리셋을 누르면 기존 `activeLayers`를 해당 조합으로 교체한다.
- sidebar에서 개별 계층을 변경하면 toolbar는 자동으로 `맞춤` 상태를 표시한다.
- 관계 preset은 노드 자체를 임의로 제거하지 않는다. 단, 선택 범위와 함께 사용할 때 관계 끝점만 남는 현상이 없도록 visibility 집합을 다시 계산한다.

### 화면 맞춤

- 버튼은 현재 표시 상태를 기준으로 한 가지 동작만 제공한다.
- 선택 범위가 `1단계·2단계`면 해당 범위를, 그렇지 않으면 현재 필터를 통과한 전체 노드를 맞춘다.
- 실제 `animatedNodePositions`에서 bounding sphere를 계산한다.
- 세로 FOV와 viewport aspect ratio를 모두 반영하고 여백 12~18%를 둔다.
- 기존 카메라 방향을 유지하며 `OrbitControls.minDistance/maxDistance` 안으로 제한한다.
- 감소 모션에서는 즉시, 일반 모션에서는 취소 가능한 단일 전환으로 이동한다.
- 표시 노드가 0개면 아무 이동도 하지 않고 접근 가능한 상태 메시지를 제공한다.
- 기존 `재정렬`은 보기별 초기 카메라 복원, `화면 맞춤`은 현재 표시 집합 fitting으로 역할을 분리한다.

### 노드 크기 기준

| 상태 | 계산 | 목적 | 기본값 |
|---|---|---|---|
| `유형` | 기존 `NODE_SIZES[kind]` | thesis·system 등 의미 위계 | 예 |
| `연결 수` | `log1p(degree)`를 p95로 정규화 후 clamp | 허브 발견 | 아니오 |
| `균일` | 전체 동일 기준 크기 | 관계선 구조만 비교 | 아니오 |

- `연결 수`는 극단적 허브 하나가 화면을 덮지 않도록 최소·최대 크기를 제한한다.
- 노드의 시각 크기, 선택 비콘, hover/raycast 허용 반경이 체감상 어긋나지 않도록 함께 검증한다.
- 데이터, 노드 순서, 관계 수는 변경하지 않는다.
- showcase 진입·복귀 시 기존 화면 상태와 함께 크기 기준을 복원한다.

## 하단 메뉴 배치 결정

- 기존 `보기`, `데이터`, `연출` 구조는 유지한다.
- 데스크톱에서는 `데이터`와 `연출` 사이에 `탐색` cluster를 추가한다.
- `탐색`: 선택 범위, 관계 표시, 화면 맞춤.
- `연출`: 기존 재정렬·자동 회전·라벨·라벨 밀도와 신규 노드 크기 기준.
- 밝기 프리셋과 커스텀은 기존 위치와 순서를 유지한다.
- 1280px 이상에서는 빈 공간을 활용하되 toolbar 전체 폭을 억지로 균등 분할하지 않는다.
- 작은 화면에서는 텍스트를 축약하고 아이콘·접근성 이름을 유지하며 기존 가로 접근 계약을 회귀시키지 않는다.

## 완료 판정 기준

- 네 옵션이 각각 독립적으로 동작하고 조합해도 노드·관계 visibility가 모순되지 않는다.
- 숨겨진 대상이 시각 출력뿐 아니라 클릭·라벨·화면 맞춤에서도 제외된다.
- `재정렬`과 `화면 맞춤`, 사실 관계와 display 연결의 의미가 UI에서 명확히 구분된다.
- 기본 상태는 기존 화면과 동일하며 사용자가 옵션을 바꿀 때만 시각 결과가 달라진다.
- 전체 자동 테스트와 Vercel 정적 빌드가 통과한다.
- 데스크톱 빈 공간은 유용한 제어로 보강되고 작은 화면 접근성은 악화되지 않는다.
