이 문서는 `화면 맞춤`이 전체 그래프에서 보기별 `재정렬`보다 과도하게 멀어지는 문제를 수정하고, 전체·부분 범위에 맞는 카메라 프레이밍을 분리하기 위한 작업 문서다.

## 개발 목적

- 전체 그래프의 `화면 맞춤`은 검증된 보기별 홈 카메라를 재사용해 `재정렬`과 같은 안정적인 구도를 제공한다.
- 필터·1단계·2단계처럼 일부 노드만 표시할 때는 실제 표시 좌표와 UI 안전 영역을 사용해 더 정밀하게 맞춘다.
- `재정렬`은 보기별 초기 구도 복원, `화면 맞춤`은 현재 표시 범위 최적화라는 사용자 기대를 유지한다.

## 개발 범위

- 전체/부분 표시 집합에 따른 하이브리드 화면 맞춤 정책
- 카메라 방향 기준 3D 좌표와 실제 viewport 안전 영역을 이용한 perspective fitting
- 상단 검색·제목, 하단 제어판, 선택 상세 패널을 피하는 안전 영역 계산
- 화면 맞춤 상태 메시지와 테스트·README 업데이트

## 제외 범위
