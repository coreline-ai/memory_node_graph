# implement_20260807_063556.md

작성 일시: `2026-08-07 06:35:56 KST`

이 문서는 parser v4로 생성된 실제 D1 지식 그래프가 현재 발광형 GUI에 로딩되지 않고 관계선도 렌더링되지 않는 문제를 복구하고, 전체 데이터와 현재 화면 투영 수량을 혼동하지 않도록 하기 위한 작업 문서다.

## 개발 목적

- 개발 모드 새로고침에서 실제 D1 또는 선택한 Gold Graph 대신 내장 DEMO 44노드·74관계가 남는 초기 로딩 문제를 수정한다.
- WebGL 관계선 Shader 컴파일 오류를 수정해 저장된 관계가 별자리·성운·궤도에서 다시 보이게 한다.
- 89,669개 엔티티·94,488개 관계를 브라우저에 전부 전송하지 않고 실제 D1에서 선택한 500노드·최대 2,000관계의 전체 지식 맵을 제공한다.
- D1 전체 수량, 투영 가능한 전체 수량, 현재 화면 표시 수량, Gold/성능 fixture를 UI에서 구분한다.

## 개발 범위

- `KnowledgeGraph` 초기 데이터 요청 Effect의 React Strict Mode 안전성
- Three.js 관계선 `ShaderMaterial`의 vertex color 계약
- API 실패 시 내장 데모를 실제 데이터처럼 유지하지 않는 명시적 오류 상태와 재시도
- 신규 `corpus` scope와 실제 D1 기반 500노드·2,000관계 서버 투영
- 하단 데이터 메뉴의 전체 지식 맵·저장소 Overview·Gold 표본·최대 밀도 데모 구분
- 좌측 통계와 제목 영역의 D1 전체/현재 표시 수량 구분
- 기존 저장소 상세, Gold Graph, 성능 fixture, 세 가지 보기와 발광 설정 회귀 검증

## 제외 범위
