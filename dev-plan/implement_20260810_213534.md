이 문서는 로컬 D1의 실제 지식 그래프를 공개 가능한 500노드·최대 2,000선 JSON 스냅샷으로 만들고, GitHub `main`을 정본으로 **Cloudflare D1이나 다른 운영 DB 없이** Vercel에 정적 배포하는 개발 범위를 고정한다. 원본 D1, OAuth 세션, 문서 쓰기 기능은 공개 배포에 포함하지 않는다.

## 개발 목적

- 현재 로컬에서만 보이는 실제 D1 corpus 투영을 로그인 없는 공유 웹에서도 동일한 발광형 GUI로 보여준다.
- 원본 D1을 Git에 올리지 않고, 공개 검증을 통과한 최소 GraphSnapshot만 GitHub에 커밋한다.
- GitHub `main` push가 Vercel Preview/Production 배포로 이어지는 재현 가능한 흐름을 만든다.
- 로컬 Markdown 수집·D1 갱신·Codex/GitHub OAuth 런타임과 공개 웹의 책임을 분리한다.
- Vercel 공개 웹은 읽기 전용 정적 JSON과 브라우저 렌더링만 사용하며 DB 연결·서버 함수·API Key를 요구하지 않게 한다.

### 핵심 판단

- **GitHub에서 Vercel로 바로 배포할 수 있다.** 단, GitHub에는 앱 코드뿐 아니라 공개용 그래프 스냅샷도 있어야 한다.
- **현재 공개 데모에는 DB가 필요하지 않다.** Vercel은 GitHub에 커밋된 JSON을 정적 asset으로 제공하고 브라우저가 이를 읽는다.
- `.wrangler`의 SQLite/D1 원본을 Git에 올리는 방식은 사용하지 않는다.
- 2,000선 모두를 실제 저장 관계라고 표시하지 않는다. `projectedFactualEdgeCount`, `displayEdgeCount`, `layer`, `origin`을 보존한다.
- 공개 스냅샷 생성은 로컬 D1이 있는 승인된 환경에서 수행하고, GitHub Actions는 커밋된 결과의 검증·빌드만 담당한다.
- 웹에서 Markdown 업로드·재색인·공동 편집이 필요해질 때만 별도 DB/백엔드 계획을 새로 만든다. 이번 정적 배포에 선행 도입하지 않는다.

## 확정 배포 구조

```text
[로컬 운영 환경]
Markdown + GitHub OAuth + Codex OAuth
                ↓ 분석·정합성 검증
         로컬 Cloudflare D1
                ↓ 공개 전용 export
snapshot.json + manifest.json + sha256
                ↓ commit / push
          GitHub main 정본
                ↓ Vercel Git Integration
     Vercel Static Assets / CDN
                ↓ browser fetch
       읽기 전용 발광형 그래프 GUI
```

- D1은 공개 데이터를 **만드는 원본 환경**에만 존재한다.
- Vercel은 D1에 접속하지 않고 `/atlas/atlas-graph-snapshot.json`만 제공한다.
- 브라우저는 정적 JSON을 메모리에서 검색·필터·렌더링하며 데이터 변경을 저장하지 않는다.
- 새 Markdown 반영은 로컬 재분석 → 공개 export → GitHub push → Vercel 재배포 순서로 수행한다.

## 공개 데이터 계약

### Git에 포함할 파일

```text
public/atlas/atlas-graph-snapshot.json
public/atlas/atlas-graph-manifest.json

```

### 스냅샷 허용 범위

| 구분 | 허용 | 제외/변환 |
|---|---|---|
| Node | 공개 source의 label, shortLabel, kind, domain, 요약, tags, 공개용 metrics | 내부 ID는 deterministic public ID로 변환 |
| Edge | 변환된 source/target, type, confidence, layer, origin, 공개용 최소 note | evidence, block ID, 내부 provider detail 제거 |
| Evidence | 초기 정적 배포에는 별도 evidence 객체를 포함하지 않음 | evidence 전체, 원문, private URL, 로컬 경로 제외 |
| Meta | schemaVersion, content hash, 생성 기준 revision, 노드·관계 수, factual/display 수 | D1 파일 경로, OAuth/runtime/job 상태 제외 |
| Source | 명시적 공개 allowlist 및 공개 확인을 통과한 GitHub source | manual source와 공개 여부 불명 source 기본 제외 |

### 수량 계약

- 노드: `1..500`
- 전체 선: `0..2,000`
- 저장 사실 관계: `projectedFactualEdgeCount`
- 비저장 시각 연결: `displayEdgeCount`
- `projectedFactualEdgeCount + displayEdgeCount === edges.length`
- 현재 검증값은 `500 nodes / 1,495 factual + 505 display = 2,000 lines`이며, 데이터 갱신 후 exporter는 특정 factual/display 비율을 강제로 맞추지 않는다.
